# 江戸の刻 ― 不定時法 疑似体験

江戸時代の「不定時法」を体感するための一枚もののWebアプリ。
日の出・日の入に合わせて一刻（いっとき）の長さが伸び縮みする様子を、文字盤・鐘の音・クイズで確かめられる。

依存ライブラリなし。`index.html` 一枚で動く。

**デモ:** https://77taka777.github.io/edonotoki/

## できること

### 体験
- 十二支と鐘数を並べた文字盤。季節を変えると昼夜の境目がアニメーションで伸縮する
- 昼／夜それぞれの一刻の長さと、「一分が現代の何倍か」を表示
- 時刻スライダーで刻名（例：夜七ツ半）・干支の刻・次の鐘までの時間を確認
- 「鐘を撞く」で捨て鐘三つ＋本鐘を再生。「今の刻」でリアルタイム表示＋刻が変わると自動で鳴る

### 鐘当て
全五問。鐘の数から現代時刻を当てる問題と、現代時刻から刻名を当てる問題が交互に出る。
選択肢には別の季節の同じ鐘の時刻が混ざるので、季節による一刻の伸び縮みを理解していないと当たらない。

### 解説
不定時法の仕組み、九から四へ数える理由、捨て鐘、文字盤の読み方。

## 技術メモ

- 単一HTML。外部依存はGoogle Fonts（Shippori Mincho）のみ
- 日の出・日の入はNOAAの近似式で計算（東京：北緯35.69 / 東経139.75）。`LAT` / `LON` 定数を書き換えれば他の土地にも対応する
- 明け六つ＝日の出の35分前、暮れ六つ＝日の入の35分後を基準とし、昼夜をそれぞれ6等分
- 鐘の音は `OfflineAudioContext` で倍音を重ねて合成 → WAVにして `<audio>` で再生。iOSのサイレントスイッチでも鳴る。合成に失敗する環境ではWeb Audioの直接再生に自動フォールバック

## ローカルで動かす

```bash
git clone https://github.com/77taka777/edonotoki.git
cd edonotoki
open index.html   # ブラウザで開くだけ
```

## GitHub Pagesで公開する

1. リポジトリの **Settings** → **Pages**
2. **Source** で `Deploy from a branch` を選択
3. Branch を `main` / フォルダを `/ (root)` にして **Save**
4. 数十秒後に https://77taka777.github.io/edonotoki/ で公開される
